# Screenshots Guide for QR Studio

Place your application screenshots in this `screenshots/` directory using the filenames below so they automatically render in the main `README.md`:

| Filename | View / Feature to Capture | Recommended Viewport |
| :--- | :--- | :--- |
| `desktop-home.png` | Full desktop layout showing Header, Left Controls, and Right Live QR Preview | `1440 × 900` (Light Mode) |
| `url-qr.png` | URL QR generation with encoded payload preview (`https://gdg.community.dev`) | `1440 × 900` |
| `email-qr.png` | Email QR form filled with recipient address, subject, and message body | `1440 × 900` |
| `wifi-qr.png` | Wi-Fi QR form showing SSID, WPA encryption, password field, and `WIFI:` payload | `1440 × 900` |
| `customization.png` | Step 3 Customize & Design panel showing Presets, custom colors, ECC, and contrast warning | `1440 × 900` |
| `recent-qr-codes.png` | Recent QR Codes section showing stored thumbnails, timestamps, Reuse, and Delete buttons | `1440 × 900` |
| `mobile-view.png` | Responsive stacked mobile layout with touch-friendly controls | `375 × 812` (iPhone SE / 13) |
| `dark-mode.png` | Full application interface with Dark Theme toggled active | `1440 × 900` (Dark Mode) |
